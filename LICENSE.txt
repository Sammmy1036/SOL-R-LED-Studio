3. WHAT THE SOFTWARE DOES TO YOUR SYSTEM
----------------------------------------

The Software works by communicating directly with the LED hardware of
Thrustmaster SOL-R flightsticks. To do this, it makes the following changes to
your computer and devices. Several of these require administrator rights.

3.1 Driver installation (Microsoft WinUSB)
    During installation, or when you click "Set up LED driver" in the
    Software, or when the Software is run with --install-driver, the Software:
      - locates each connected SOL-R stick's vendor-specific LED interface
        (USB interface MI_01, USB IDs 044F:042A and 044F:0422);
      - changes that interface's device setup class to "Universal Serial Bus
        devices";
      - installs Microsoft's WinUSB driver (winusb.inf, supplied with and
        signed as part of Microsoft Windows) on that interface using the
        Windows Setup API;
      - writes a "DeviceInterfaceGUIDs" value to that interface's registry key
        under HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Enum\...\Device Parameters;
      - restarts that interface using the Windows "pnputil" tool.
    The joystick interface of the stick (MI_00, used for axes and buttons) is
    not modified by the Software. No drivers other than Microsoft's WinUSB are
    installed. A log of these steps is written to
    %APPDATA%\SolR-LED\driver-setup.log.

3.2 Driver removal
    When the Software is uninstalled, or run with --uninstall-driver, it
    removes the device entries for SOL-R LED interfaces that use WinUSB
    (using "pnputil /remove-device") and asks Windows to rescan for hardware,
    returning those interfaces to their prior driverless state. Removal may
    not succeed in every configuration; you can also remove the driver
    manually in Windows Device Manager.

3.3 Communication with your hardware
    The Software sends unofficial USB commands to your SOL-R sticks to change
    LED colors and brightness, and to run lighting effects, which send a
    continuous stream of commands while active. These commands are based on
    independent, community reverse engineering and are not documented,
    tested, or supported by Thrustmaster. Firmware indicator lights (such as
    D1/D2) may flicker while effects run.

3.4 Files and settings
    The Software stores its settings, profiles and logs in
    %APPDATA%\SolR-LED\. If you enable "Start with Windows", it creates a
    startup entry in your Windows Startup folder. The installer places program
    files in the installation folder you choose and creates shortcuts.

3.5 Process monitoring
    If "Switch profiles for games" is enabled, the Software periodically reads
    the names of running programs on your computer to detect the games you
    have chosen. This information is used only locally and is never stored
    beyond your chosen trigger list or transmitted anywhere.

3.6 Networking
    The Software does not send data over the internet and contains no
    telemetry. It opens a local-only connection on 127.0.0.1 (port 47612)
    solely to prevent more than one copy from running at the same time.

3.7 Possible side effects
    Because the LED interface is assigned to WinUSB, other software that
    expects to use that interface (for example, manufacturer tools or
    firmware updaters) may not be able to access it while the Software's
    driver setup is in place. Only one program at a time can use the LED
    interface.
